# Автоматическая сборка Android APK

Workflow **Build Android APK** запускается в GitHub Actions после обновления `main`/`master` или вручную через **Run workflow**. Он проверяет тесты, собирает веб-файлы, создаёт Android-проект при отсутствии, добавляет возврат авторизации `knailsfinance://auth`, генерирует иконки и собирает APK с локально включённым интерфейсом, а не ссылкой на предпросмотр.

## Перед первым запуском
1. Обновите подключённый GitHub-репозиторий изменениями из Lovable.
2. Если файл `.env` с публичной конфигурацией подключения отсутствует в репозитории, добавьте в GitHub → Settings → Secrets and variables → Actions → Variables значения `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY` из конфигурации проекта. Приватные ключи сервера здесь не нужны.
3. Откройте Actions → Build Android APK → Run workflow.
4. После успешного завершения скачайте **nails-by-kristina-debug-apk** из Artifacts, распакуйте ZIP и установите APK на Android.

Это **debug APK для проверки**, не подписанный релиз для магазина. Для постоянных обновлений и публикации нужен ваш сохранённый ключ подписи; он не создаётся и не сохраняется в исходниках автоматически. Не удаляйте установленное приложение без экспорта резервной копии.

## Если сборкой занимается локальный Codex
Работайте в клоне репозитория на компьютере с Android Studio, Android SDK и JDK 17:

```sh
npm install
npm test
npm run build
# Только если папки android ещё нет:
npx cap add android
node scripts/prepare-android.mjs
npx cap sync android
npx cap open android
```

После любых обновлений сначала получите свежий код из подключённого репозитория, затем выполните `npm run build` и `npx cap sync android`. Сборка APK: `android/gradlew assembleDebug` (Windows: `android\gradlew.bat assembleDebug` из папки android).

## Обязательная проверка на телефоне
- Gboard и Samsung Keyboard: сохранить «Наращивание» и «Гель лак» сразу после ввода, не нажимая пробел.
- Создать и отредактировать услугу и категорию, выйти из раздела и убедиться, что полный текст сохранился.
- В заметках клиентов, календаря, доходов, расходов, напоминаний и таймера: сначала ввести русский текст, затем менять сумму/дату/выбор, сохранить и открыть снова.
- Проверить сокращение и полное удаление текста: старый текст не должен возвращаться.
- Проверить вход, сброс пароля с возвратом из почты, таймер после сворачивания, фото и экспорт/импорт резервной копии.
- Проверить ошибки сети: формы не закрываются и текст остаётся для повторной попытки.

Браузерные тесты моделируют события композиции, но не заменяют настоящий Android WebView и клавиатуру. Сборка в GitHub и проверки на вашем телефоне выполняются после получения изменений репозиторием.
